# WFLib docs

Mod id `wflib`, package `com.wf.wflib`. Shared Warfactory library: server-simulated missiles and ordnance,
a pluggable warhead/explosion framework, autonomous drones, construction, kinetic rounds, multiblock doors,
the look-at probe, recon/sonar, and the UI widget system other mods build HUDs from.
